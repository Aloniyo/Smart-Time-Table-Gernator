Our project proposes a Smart Timetable Generation & Scheduling System that simplifies the creation of timetables under the multidisciplinary framework of NEP 2020 while also supporting classroom and shift management.

The system works in the following way:

1. Input & Mapping

Authorized users log in to enter teacher availability, subjects, classrooms, and slots.

The system begins mapping assignments step by step, saving each allocation instantly in a log.



2. Conflict Handling with Backtracking

At each step, the system checks for conflicts (teacher overlap, classroom clash, or workload imbalance).

If a conflict is found, the system backtracks using the log, marks the conflicting step as incomplete, and tries alternate allocations.

This ensures that the same mistake is not repeated.



3. Optimized Output

The algorithm continues until it produces the best possible timetable with minimum conflicts.

Multiple optimized timetable options can be generated for review.

Any unresolved issues are listed in a separate Issue Report for manual correction.



4. Platform Features

Login and access control for authorized personnel.

Multi-department and multi-shift scheduling support.

Review and approval workflow for competent authorities.

Suggestions for rearrangements if fully optimized solutions are not possible.




This approach makes timetable creation systematic, flexible, and reliable, ensuring institutions can manage diverse courses, teachers, and departments effectively while saving time and reducing errors.
